`site.config.json` is imported by `lib/site-config.ts`, which means webpack bundles the
whole file into the client JavaScript. The roster's `_needsConfirmation` array is therefore
**deliberately stripped** during sync - internal project notes must not ship to visitors.

Stripping it silently would be the laundering trap recorded in
[business-facts.md](business-facts.md) section 0: a reader of the repo manifest alone sees a
clean, complete NAP and reasonably concludes it is confirmed. **It is not.** This file is
where those assumptions stay visible.
