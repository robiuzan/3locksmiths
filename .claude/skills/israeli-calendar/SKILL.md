# The Israeli calendar — data, not code

The calendar is **committed data** consumed offline. It is generated by a human-run, networked
script (`scripts/calendar-sync.mjs`) that never runs inside `npm run enrich` — the same split as
the image pipeline (CLAUDE.md §6). The consuming doctrine is `/dynamic-presence`; the plan is
`docs/dynamic-presence-plan.md` §4.1–4.2 (the as-built notes there win over the original steps).

## Sources, and what each one lacks

| Source                                                                                                                                     | Gives                                                                                                                                          | Lacks                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Hebcal REST `…/hebcal?v=1&cfg=json&maj=on&min=on&mod=on&nx=off&mf=off&ss=off&s=off&i=on&lg=he&c=on&M=on&geonameid=293397&month=x&year=<Y>` | chagim, Yom Kippur, Tisha B'Av's fast times, Yom HaShoah, Yom HaZikaron, Rabin day — Israel schedule — and Tel Aviv candle-lighting / havdalah | the 24 Tishrei memorial, 7 October, election days |
| `content/enriched/_calendar.overlay.json` (hand-kept)                                                                                      | those civic days, and `verifiedThrough` — the date a human has checked the overlay to                                                          | needs a human once a year                         |

- **`i=on` is mandatory.** The default is the diaspora schedule, which moves Shmini Atzeret /
  Simchat Torah and the last day of Pesach by a day. The generator refuses a feed that carries
  "Pesach VIII" or "Shavuot II" — proof the flag was honoured.
- **`mf=off` is deliberate.** The owner's quiet list (2026-09-29) names Yom Kippur and Tisha B'Av;
  the minor fasts (10 Tevet, Ta'anit Esther, 17 Tammuz, Tzom Gedaliah) are not quiet days.
- Use the `hebrew` field; `title` carries nikud.
- Hebcal data is **CC BY 4.0** — the credit is in the generated file and in the served
  `public/assets/live-schedule.json`.
- **Never `@hebcal/core`** in anything that ships (GPL-2.0, 3.8 MB). **Never `Intl`** in the
  enrich chain or the gates: CI (Node 20) and the workstation (Node 24) disagree on ICU. The
  offsets come from `lib/live/israel-time.mjs` (the two-line DST rule), which the generator
  cross-checks against the platform's tz database so a law change fails loudly.

## Windows — the four kinds, and the shape

```json
{
  "id": "yom-kippur-2027-10-11",
  "kind": "quiet",
  "from": "2027-10-10T12:00:00+03:00",
  "until": "2027-10-11T19:20:00+03:00",
  "label": "יום כיפור",
  "source": "hebcal-il"
}
```

| kind          | what                                                                                                                                                                                                                                                                                    | quiet? |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `shabbat`     | candle-lighting − 60 min → havdalah + 30 min (Tel Aviv, from Hebcal)                                                                                                                                                                                                                    | yes    |
| `chag`        | the same span when a yom-tov day falls inside it (a chag running into Shabbat is one window)                                                                                                                                                                                            | yes    |
| `quiet`       | Yom Kippur, Tisha B'Av, Yom HaShoah, Yom HaZikaron, Rabin day, the overlay's memorial days — from **12:00 on the eve** to 20:30 (nightfall; Yom Kippur/Tisha B'Av to the fast's end + 30); election day all day                                                                         | yes    |
| `pre-shabbat` | Thursday 17:00 → Friday 14:00 before each Shabbat — the slot the weekly advice line repeats in via `during: "pre-shabbat"`. Emitted even when the Thursday is a quiet day (the compiler subtracts the quiet span, so the slot starts when the day ends); none when the Friday is a chag | **no** |

- **Explicit offsets, always, of the right season.** `+03:00` until the clocks go back at 02:00
  on 25/10/2026, `+02:00` after, `+03:00` again from 26/03/2027, `+02:00` from 31/10/2027.
  `check-campaigns` rejects an authored bound in the wrong season. A date-only string is UTC
  midnight = 03:00 in Israel and is forbidden.
- **Legal date moves are data, not arithmetic:** Yom HaZikaron/HaAtzmaut shift when 4/5 Iyar falls
  on Fri/Thu/Sun; Yom HaShoah shifts off Friday/Sunday; Rabin day is observed on the Thursday when
  12 Cheshvan is a Friday (22/10/2026, 11/11/2027); 24 Tishrei moves to Sunday when on Shabbat.
  Hebcal (`i=on`) or the overlay carry them — never compute them.
- **5787 is a leap year:** Adar I and Adar II (Purim Katan 21/02/2027, Purim 23/03/2027). Never
  match on a month name; match on the generated window.
- No `labelDate` is emitted; nothing renders a calendar label to a visitor today.

## Quiet days — the owner's list (2026-09-29)

All seasonal copy goes silent; only the evergreen line shows — and, on Shabbat and chag only,
the summer safety line (owner, 2026-10-01).

- **Memorial days:** Yom HaShoah (Tue 04/05/2027), Yom HaZikaron (Tue 11/05/2027, from the eve),
  the **24 Tishrei** memorial (Mon 05/10/2026, Mon 25/10/2027 — government decision 1525, not in
  Hebcal), **7 October** (civil anniversary).
- **Fast days:** Yom Kippur (Mon 21/09/2026, Mon 11/10/2027), Tisha B'Av (Thu 12/08/2027). Not
  the minor fasts.
- **Civic:** Knesset election day (Tue 27/10/2026 — the statutory third Tuesday of Cheshvan, a
  public day off), Rabin memorial (Thu 22/10/2026, Thu 11/11/2027).
- **Shabbat and every chag** themselves.

Precedence: `status.json` override (Phase 3) → hard quiet day (kind `quiet`: evergreen only) →
safety → Shabbat/chag (evergreen, no seasonal line) → seasonal → evergreen. **Two grades of
quiet** (owner, 2026-10-01): a memorial day, fast or civic day silences everything; Shabbat and
chag silence the seasonal lines only, so the hot-car safety line stays on through them (no card
opens on Shabbat even for it). The **compiler** (`lib/live/compile.mjs`) subtracts the quiet
windows at build time, so an authored window is not cut around them by hand; `check-campaigns`
then fails if any compiled interval touches a window it may not (all quiet kinds for a seasonal
line, the hard ones for a safety line), or reaches past the calendar's last quiet window (beyond
it no Shabbat is known), and the simulator re-asserts it for every hour of 400 days.

## The windows that ship

The register is `content/enriched/_campaigns.mjs`; its header comment is the authoring guide
(tokens, the 46-character row, the `safety-` prefix, `during`, the priority ladder 10/20/30/50,
sources, lifecycle). The plan's Phase 1 block lists the six lines with their dates.

Seasonality for `מנעולן` is only about ±10 % across the year (Google Trends, 5 years); the value of
this layer is relevance and trust, not catching a surge. The real surges are wartime — which is what
`status.json` `quiet`/`reduced` is for (Phase 3), never an automated reaction to alerts.

## Audiences the calendar must respect

- **Bnei Brak** (9604): no Shabbat-work messaging on that page; the weekly line is a home check
  ("two car keys on one ring?"), never "book before Shabbat".
- **Lod** (mixed city) and Haifa's Christian community: Ramadan/Eid (≈ 08/02 → 09/03/2027) and
  Christmas are an **owner decision**, not a default — nothing ships for them until asked.
- Hebrew is the only language on the site; a Jewish-only calendar is a choice that is recorded here.

## Gates

- `scripts/calendar-sync.mjs` itself refuses to write when: a Friday night in range is not inside
  a quiet window; a named day of any year is missing (Yom Kippur, Yom HaShoah, Yom HaZikaron,
  Tisha B'Av, Rabin day); fewer than the expected chag windows; a diaspora-only day appears; a
  Shabbat/chag span is over 80 h (a havdalah went missing); a candle-lighting on or before
  `verifiedThrough` has no havdalah; an overlay day did not survive; or any kind has **fewer**
  windows than the committed file (`--force` overrides that one). `--check` exits 1 on drift.
- `check-campaigns` (prebuild) fails when: a calendar kind is unknown; an overlay day has no quiet
  window (the overlay was edited without the sync); `coversThrough` ≠ the overlay's
  `verifiedThrough`; a Saturday noon inside the range is not quiet; a compiled interval touches a
  hard quiet day, a seasonal one touches a Shabbat or chag, or any reaches past the last quiet
  window; timed windows exist with no calendar. It warns from
  **180 days** before the calendar ends and fails at **60**; `LIVE_GATES=lapsed-ok` turns only
  that and the runway rule into warnings.
- `check-schedule` (node:test) runs the resolver, the compiled schedule and the shipped inline
  script against each other for every hour of the next 400 days and both sides of every
  boundary, including the DST nights and the two Adars.
- The weekly reminder routine (Phase 3) will read the **live** `public/assets/live-schedule.json`
  and warn the owner's phone (ntfy) before the runway ends and before each quiet day.

## Regenerating (once a year, or when the overlay changes)

1. Extend the overlay: add the next year's 24 Tishrei memorial and 7 October (and any election),
   each with a source a human checked, and raise `verifiedThrough`. An overlay edit alone changes
   nothing — the gate fails until step 2 runs.
2. `node scripts/calendar-sync.mjs` (networked; human-run; commits nothing). `--check` first shows
   whether the committed file still matches the sources.
3. Review the diff of `content/enriched/_calendar.json` by eye — every new `quiet` window, every
   moved date.
4. `npm run format`, `npm run enrich` (the pipeline compiles the schedule from the calendar), then
   the gate, then a human deploy. The calendar is in `.prettierignore`; never format or edit it
   by hand.
