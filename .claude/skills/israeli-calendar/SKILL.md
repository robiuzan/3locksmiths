# The Israeli calendar — data, not code

The calendar is **committed data** consumed offline. It is generated by a human-run, networked
script (`scripts/calendar-sync.mjs`) that never runs inside `npm run enrich` — the same split as the
image pipeline (CLAUDE.md §6). The consuming doctrine is `/dynamic-presence`; the plan is
`docs/dynamic-presence-plan.md` §4.1–4.2.

## Sources, and what each one lacks

| Source                                                                       | Gives                                                                                                       | Lacks                                                                                          |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Hebcal REST `…/hebcal?v=1&cfg=json&maj=on&min=on&mod=on&year=<Y>&i=on&lg=he` | chagim, fasts, Yom HaShoah, Yom HaZikaron, Yom HaAtzmaut, Rabin day, Sigd — Israel schedule, correct גרשיים | the 24 Tishrei Iron Swords memorial, 7 October, election days, school vacations, sundown times |
| `content/enriched/_calendar.overlay.json` (hand-kept)                        | everything above that Hebcal lacks, plus the padded Shabbat window                                          | needs a human once a year                                                                      |

- **`i=on` is mandatory.** The default is the diaspora schedule, which moves Shmini Atzeret /
  Simchat Torah and the last day of Pesach by a day.
- Use the `hebrew` field; `title` carries nikud. Normalise ktiv to the house style (`הזיכרון`).
- Hebcal data is **CC BY 4.0** — the credit line goes into the generated file header and `docs/`.
- **Never `@hebcal/core`** in anything that ships (GPL-2.0, 3.8 MB). **Never `Intl`** for output:
  he-IL prints `5.12.2026`, not `dd/mm/yyyy`; Hebrew years print `5787`, not `תשפ״ז`; CI (Node 20)
  and the workstation (Node 24) disagree on ICU. Every user-visible date is pre-rendered by the
  generator as `dd/mm/yyyy`; Hebrew years in letters come from a small lookup table.

## Windows — the shape

```json
{
  "id": "yom-kippur-5788",
  "kind": "quiet",
  "from": "2027-10-10T12:00:00+03:00",
  "until": "2027-10-11T20:30:00+03:00",
  "label": "יום כיפור",
  "labelDate": "11/10/2027",
  "source": "hebcal-il"
}
```

- **Explicit offsets, always.** `+03:00` until the clocks go back at 02:00 on 2026-10-25, `+02:00`
  after, `+03:00` again from 2027-03-26. A date-only string (`new Date('2026-10-05')`) is UTC
  midnight = 03:00 in Israel and is forbidden.
- **Sundown-aware, padded, not astronomical:** memorial days and fasts start **12:00 on the eve**;
  chagim at **candle-lighting minus 60 min**; festive copy after Yom HaZikaron not before
  **nightfall** (the law: it ends at nightfall, and Yom HaAtzmaut begins as it ends); Shabbat as a
  fixed padded window **Fri 15:00 → Sat 21:00** year-round (covers the earliest candle-lighting in
  December and the latest havdalah in June).
- **Legal date moves are data, not arithmetic:** Yom HaZikaron/HaAtzmaut shift when 4/5 Iyar falls
  on Fri/Thu/Sun; Yom HaShoah shifts off Friday/Sunday; 24 Tishrei moves to Sunday when on Shabbat.
  Take them from Hebcal (`i=on`) or the overlay — `Intl` cannot compute any of them.
- **5787 is a leap year:** Adar I and Adar II (Purim Katan 21/02/2027, Purim 23/03/2027). Never
  match on a month name; match on the generated window.

## Quiet days — the owner's list (2026-09-29)

All promotional and seasonal copy goes silent; only the evergreen line shows.

- **Memorial days:** Yom HaShoah (04/05/2027), Yom HaZikaron (from the eve, 10–11/05/2027), the
  **24 Tishrei** Iron Swords memorial (Mon 05/10/2026, Mon 25/10/2027 — a government decision, not
  in Hebcal), **7 October** (civil anniversary). Note that Simchat Torah (22 Tishrei, 03/10/2026) is
  the Hebrew-date anniversary of 7 October — treat it as quiet, not festive, at least this year.
- **Fast days:** Yom Kippur (11/10/2026, 11/10/2027), Tisha B'Av (12/08/2027).
- **Civic:** Knesset election day (Tue 27/10/2026, a public day off), Rabin memorial (22/10/2026).
- **Shabbat and every chag** themselves (the padded weekly window plus each chag's window).

Precedence in the browser: `status.json` override → quiet → safety → seasonal → evergreen. A
seasonal window that overlaps a quiet window **fails the build** (`check-campaigns`); the resolver
also enforces it at runtime, because belt and braces is the point.

| Winter remote battery      | 01/11 → 31/03                     | key-battery guide (9210)                                |
| Pesach cleaning, lost keys | 13/04 → 28/04/2027 (MoE vacation) | the relevant guide                                      |
| Back to school, spare key  | 15/08 → 10/09/2027                | spare-key advice                                        |
| Before Shabbat (weekly)    | Thu 17:00 → Fri 14:00             | spare key mid-week (the tested Bnei Brak framing, 9604) |

Seasonality for `מנעולן` is only about ±10 % across the year (Google Trends, 5 years); the value of
this layer is relevance and trust, not catching a surge. The real surges are wartime — which is what
`status.json` `quiet`/`reduced` is for, never an automated reaction to alerts.

## Audiences the calendar must respect

- **Bnei Brak** (9604): no Shabbat-work messaging on that page; the tested framing is "get a spare
  key mid-week".
- **Lod** (mixed city) and Haifa's Christian community: Ramadan/Eid (≈ 08/02 → 09/03/2027) and
  Christmas are an **owner decision**, not a default — nothing ships for them until asked.
- Hebrew is the only language on the site; a Jewish-only calendar is a choice that is recorded here.

## Gates

- `check-campaigns` fails when: a window lacks an offset; seasonal overlaps quiet; two windows tie on
  priority; fewer than **30 days** of authored windows remain; the calendar ends less than
  **12 months** out; a label uses ASCII quotes (extend `check-typography` with `ל״ג`, `חוה״מ`,
  `ט״ו`).
- The `node:test` simulator runs `resolve(schedule, instant)` for every hour of the next 400 days
  and asserts the DST nights (2026-10-25, 2027-03-26), the Adar windows, and that no quiet hour ever
  resolves to a promo.
- The weekly reminder routine reads the **live** `public/assets/live-schedule.json` and warns the
  owner's phone (ntfy) 30 days before the runway ends and 7 days before each quiet day (set
  Business Profile special hours).

## Regenerating (once a year, or when the overlay changes)

1. `node scripts/calendar-sync.mjs --years 2026,2027,2028` (networked; human-run; commits nothing).
2. Review the diff of `content/enriched/_calendar.json` by eye — every new `quiet` window, every
   moved date.
3. `npm run enrich` (the pipeline reads the calendar for the schedule asset), then the gate, then a
   human deploy. The calendar is in `.prettierignore`; do not format it by hand.
